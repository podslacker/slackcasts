Overview

The opening keynote at Google Cloud Next '26 highlighted how Google Cloud is moving from AI pilots to widescale production with the Gemini Enterprise Agent Platform. Sundar Pichai and Thomas Kurian outlined massive infrastructure investments, real‑world AI successes inside Google, and showcased new tools that let enterprises build, govern, and secure “agentic” AI workflows across the entire organization.

New Features & Announcements

  • Gemini Enterprise Agent Platform – End‑to‑end system that connects data, models, and agents to deliver autonomous, secure business flows.
    Timeline: announced today (preview available)
    Availability: Private preview (early customer access)

  • Gemini 3.1 Pro (preview) – Advanced reasoning model optimized for complex workflow orchestration.

  • Gemini 3.1 Flash Image (Nano Banana 2) – High‑fidelity visual‑asset generation model (preview).

  • Veo 3.1 Lite – Cost‑effective video generation model for high‑volume use cases (preview).

  • Lyria 3 Pro – Enterprise‑grade audio and music model (preview).

  • Claude Opus 4.7 support – Added Anthropic model integration.

  • Agent Studio (low‑code) – Natural‑language UI for building and deploying agents.

  • Agent Registry & Skills/Tools Registry – Centralized catalog for agents, reusable skills, and GCP/Workspace services.

  • Agent Marketplace – Access to pre‑built agents from partners such as Atlassian, Box, Oracle, ServiceNow, Workday, etc.

  • Model Context Protocol (MCP) integration – Allows agents to call any MCP‑compatible service, including all GCP APIs.

  • Agent Identity & Agent Gateway – Cryptographic IDs and central policy enforcement for zero‑trust security.

  • Model Armor – protects proprietary models and data from leakage.

  • Agent Observability (OTel‑compliant) – Full telemetry, tracing, and logging for debugging and performance tuning.

Topics Covered

  • AI at Google Scale – 75 % of Google Cloud customers now use AI; internal Google teams generate ~75 % of new code with AI, achieving 6× faster migrations and 90 % reduction in threat‑mitigation time.
  • Investment Roadmap – Capital‑expenditure up from $31 B (2022) to $175–185 B this year, with >50 % of ML compute earmarked for the cloud by 2026.
  • Agentic Era Vision – Shift from “can we build an agent?” to “how do we manage thousands of agents?” and the need for a unified stack (chips, models, data, agents, security).
  • Gemini Enterprise Launch – Described as “mission control” for the agentic enterprise; integrates data, agents, and business goals into a single flow.
  • Model Portfolio – Preview releases of Gemini 3.1 Pro, Flash Image, Veo Lite, Lyria Pro, and Anthropic models, plus partnership with Apple for next‑gen Siri‑like intelligence.
  • Customer Success Stories – Citi Sky (AI wealth advisor), Honeywell digital twins, Liverpool shopping assistant (10× ROI), NASA Artemis II flight‑readiness agents.
  • Platform Architecture – Layers: AI Hypercomputer (hardware), Agentic Data Cloud (trusted context), Agentic Defense (security), Agentic Platform (build/deploy/manage), Agentic Task Force (pre‑built agents).
  • Governance & Security – Zero‑trust verification, Agent Identity, Model Armor, centralized Agent Gateway, and robust observability.

Key Takeaways

  • The AI transition is now at enterprise production scale; the focus is on unified, secure agentic workflows.
  • Gemini Enterprise provides the full stack—from specialized hardware to low‑code tooling—to build, govern, and scale agents across any organization.
  • New models (Gemini 3.1 Pro, Flash Image, Veo Lite, Lyria Pro) are in preview, delivering higher quality output with optimized cost.
  • Security is baked in: cryptographic agent IDs, zero‑trust policies, and Model Armor protect data and models throughout the lifecycle.
