5️⃣ Quick Reference – How to Get Started

Step Action Resource
1. Explore Sign up for the Agent Platform public preview (via Google Cloud Console). https://cloud.google.com/agent-platform
2. Install CLI gcloud components install agent-cli (or download from the Developer portal). CLI Docs
3. Scaffold agent-cli init my‑agent --template=rag‑orchestration Sample templates
4. Define Skills Write a JSON/YAML skill file, then agent-cli skill register my‑skill.yaml. Skill Spec
5. Deploy agent-cli deploy --runtime=standard --memory=4Gi. Deployment guide
6. Observe Open the Agent Dashboard → monitor latency, errors, and memory usage. Observability UI
7. Govern Add IAM policies via Agent Identity UI; enable Model Armor for prompt‑injection protection. Governance docs
8. Optimize Run built‑in evals: agent-cli eval run --suite=core‑benchmarks. Eval Suite
